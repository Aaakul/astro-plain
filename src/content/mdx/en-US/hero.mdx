# Astro Plain <Icon name="rss" href="/en-US/rss.xml" title="RSS" size="0.875em" />

## A Minimalist Multilingual Static Blog Template for Astro

Astro Plain is built with vanilla CSS and TypeScript, free of UI/CSS frameworks to remain lightweight and easy to customize.

Featuring core capabilities of modern blogs such as built-in search, Disqus comments, multilingual support, and useful MDX components, it adheres to SEO best practices to help you quickly build your personal website.
