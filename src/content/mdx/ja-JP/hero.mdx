## ミニマルな Astro 多言語静的ブログテンプレート

Astro Plain はバニラ CSS と TypeScript を採用し、UI/CSS フレームワークに依存せず、軽量でカスタマイズしやすい状態を維持しています。

内蔵検索、Disqus コメント機能、多言語対応、実用的な MDX コンポーネントなどモダンなブログのコア機能を備え、SEO のベストプラクティスに準拠することで、個人ウェブサイトの迅速な立ち上げを支援します。
